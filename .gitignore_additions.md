# Additional .gitignore Patterns for Agno Development

Recommended additions to supplement the existing `.gitignore`:

```gitignore
# Ruff linter cache
.ruff_cache/

# Coverage reports
htmlcov/
.coverage
.coverage.*
coverage.xml

# Virtual environments (additional names)
.venv/
.venvs/
venv/
env/

# Jupyter
.ipynb_checkpoints/
*.ipynb

# macOS
.DS_Store

# Windows
Thumbs.db

# Editors
.idea/
.vscode/settings.json

# Secrets / local config
*.env.local
secrets.yaml
```
