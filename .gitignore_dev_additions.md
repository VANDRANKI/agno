# Recommended .gitignore additions for Agno contributors

Add the following entries to the root `.gitignore` if they are not already
present:

```gitignore
# Python
__pycache__/
*.py[cod]
*.pyo
.Python
pip-wheel-metadata/
*.egg-info/
.eggs/
build/
dist/
.pytest_cache/
.mypy_cache/
.ruff_cache/
htmlcov/
.coverage
.coverage.*
coverage.xml

# Virtual environments
.env
.venv/
venv/
.envs/

# Jupyter
.ipynb_checkpoints/

# IDE
.idea/
.vscode/
*.swp
*.swo

# macOS
.DS_Store

# Agno-specific
.context/
```

Note: The `.context/` directory is already listed in `.gitignore` by project
convention and is used for conductor scratch notes.
